# Flat `IfStatement` arms in the compiler AST {#if-statement-flat-arms}

## Summary

The compiled `IfStatement` expression now stores an `if` / `else if` chain as a flat `arms: Vec<IfArm>` list plus an optional `else_block`, instead of nesting another `IfStatement` inside `else_block` for each `else if`.
The public `predicate` and `if_block` fields are replaced by `arms`.
This only affects Rust code that constructs or pattern-matches `vrl::compiler::expression::IfStatement`; VRL programs and the `compile()` API are unaffected.

## Migration

Build the statement with `IfStatement::new` and one `IfArm` per `if` / `else if` branch.

#### Old

```rust
IfStatement {
    predicate,
    if_block,
    else_block,
}
```

#### New

```rust
IfStatement::new(
    vec![IfArm {
        predicate,
        block: if_block,
    }],
    else_block,
)
```
